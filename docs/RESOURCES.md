## About this dataset

This GitHub repository provides a **subset** of structured JSON for developers. The canonical, searchable database with audio, kanji notes, and generators is always on **[JapaneseNamer.info](https://www.japanesenamer.info/)**.

When you ship a project using this data, please link to the site (see [README citation](../README.md#-citation--attribution)).
